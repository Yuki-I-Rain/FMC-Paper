# FMC Paper · 最少步试卷编辑器

Vite + 原生 JavaScript 实现的三阶魔方最少步（FMC）试卷生成器。支持中英文编辑、18 种转动严格校验、实时六面图预览、PDF / PNG 导出与 A4 打印，全程本地运行，不上传任何填写内容。

## 功能简介

- **中英文双语**：一键切换界面语言，支持填写中文姓名与比赛名称
- **严格输入校验**：仅支持六面单层转动（`U D L R F B` 及 `'` `2`），实时高亮错误并统计步数
- **实时预览**：六面状态图与 A4 试卷排版随输入同步更新
- **多格式导出**：按需加载 PDF / PNG 导出模块，打印不加载 PDF 库
- **本地隐私**：所有处理在浏览器本地完成，不使用 CDN、在线字体或后台服务
- **完整中文字体**：内置 Noto Sans SC，支持任意中文输入的预览、打印与导出

## 快速开始

### 在线使用

无需安装，直接访问在线版本：

👉 **https://yuki-i-rain.github.io/FMC-Paper/**

### 本地部署

本项目构建后为纯静态站点，可部署到任意静态 HTTP 服务，服务端不需要 Node.js。

#### 方式一：从源码构建（推荐）

需要 **Node.js 20.19+ 或 22.12+**（建议使用受支持的 LTS 版本，本工程在 Node.js 22.16 验证）。

```sh
# 1. 克隆仓库
git clone https://github.com/Yuki-I-Rain/FMC-Paper.git
cd FMC-Paper

# 2. 安装依赖
npm ci

# 3. 构建生产版本（输出到 dist/）
npm run build

# 4a. 用 Vite 预览服务器运行（最简单）
npm run preview
# 默认地址 http://127.0.0.1:4173/

# 4b. 或用任意静态服务器托管 dist/ 目录
npx serve dist
# 或 Python：
#   cd dist && python -m http.server 8080
```

将 **整个 `dist/` 目录** 放到任意静态 HTTP 服务下即可。

#### 方式二：开发模式运行

适合修改代码或调试，支持热更新：

```sh
npm ci
npm run dev
```

默认地址 `http://127.0.0.1:5173/`。

> **注意**：不要直接双击 `index.html` 打开。拆分后的 ES 模块需要通过 HTTP 服务加载。

## 部署说明

- 将 **整个 `dist/` 目录的内容** 放在任意静态 HTTP 服务下即可运行，服务本身不需要 Node.js 或 npm。
- 支持部署在网站子目录中，必须保留 `assets/` 子目录及文件名。
- 部署新版本时完整替换构建文件；保留旧哈希资源到现有页面会话结束，可避免已打开的旧页面在导出时找不到组件。
- 本项目不包含 Service Worker、手机网页发布或双击版生成步骤。断网使用是指本机服务仍在运行，不能将远程网站首次打开后的浏览器缓存视为完整离线支持。
- 首次安装 npm 依赖需要联网。安装完成后，可以断网启动本地服务，编辑、导出和打印均在本机完成。

## 工程结构

```text
index.html             页面 UI 与模块入口
src/
  app.js               页面状态、表单、语言与导出菜单
  core.js              严格输入解析、魔方计算
  sheet.js             预览 / 导出 / 打印共用的 SVG 试卷
  i18n.js              中英文文案
  styles.css           屏幕、窄屏与打印样式
  font.js              完整中文字体加载与内存复用
  print.js             浏览器打印生命周期
  credits.js           按需读取许可证文本
  export/              PDF、PNG 及公共导出辅助代码
  assets/              字体与图标
  licenses/            原组件和字体的许可证原文
scripts/               构建时汇总 npm 生产依赖许可证
tests/                 独立魔方参考模型与浏览器回归检查
public/                随构建复制的依赖许可证汇总
dist/                  可直接部署的生产构建（构建后生成）
```

第三方库由 npm 安装，`package-lock.json` 锁定版本。只修改 `src/` 和页面源文件，再重新构建；不要直接修改 `dist/`。

## 构建策略

- HTML 不内嵌业务脚本、第三方库、样式或字体 Base64。
- Vite 压缩 JavaScript / CSS 并剔除未使用代码，生成带内容哈希的资源文件。
- 选择 PDF 后才加载 jsPDF、svg2pdf.js；选择 PNG 后加载独立 PNG 导出模块。打印不加载 PDF 库。
- 导出模块加载失败后再次选择导出，会使用新的请求地址重试，避免浏览器缓存失败记录。已填内容保留，成功加载的模块在当前页面内复用。
- jsPDF 自带的其他转换功能可能产生额外的异步文件；本工具不在启动时加载它们。
- 保留约 10.6 MB 的完整 Noto Sans SC 字体，以支持用户输入任意中文姓名和比赛名称。字体单独请求一次，预览、打印、PDF 和 PNG 复用相同字节。PNG 生成过程会临时将字体嵌入内存中的 SVG，这是输出图片所需，不会重新写入页面 HTML。
- 字体失败时显示重试按钮；导出失败时恢复控件。组件文件缺失时检查服务和完整构建文件，并按页面提示重试。

## 验证

```sh
npm test
npm run build
npm run test:browser
```

单元测试使用独立的三维贴纸模型验证全部 18 种转动、逆转动、四次还原及输入校验。

浏览器测试会自动启动临时本地服务，在网站子目录运行构建版本，并阻止外网请求。测试菜单、中英文、字体失败重试、按需加载、导出、打印排版及错误输入，结果文件写入 `test-results/`。

浏览器测试优先使用已安装的 Chrome。若没有，可执行 `npx playwright install chromium`（该安装步骤需要联网）。也可设置 `CHROME_PATH` 指向浏览器可执行文件。

可选环境变量 `FMC_BASELINE` 指向原单文件 HTML；开启后额外比较空白卷和中英文填写卷的 SVG，确认试卷模板没有变化。

打印测试会验证 A4 排版及调用流程，不会向实体打印机发送任务。实际纸张、缩放、页眉页脚和打印机选择仍由浏览器打印对话框控制。
